# docs/history: the session handoffs and agent-run logs that are finished

The record of how the toolkit got here, moved out of `docs/` on 2026-11-02 (ROADMAP 0.9's housekeeping, done early at the
review of that day). Each file is as it was last written: a branch's handoff is the brief its merge was made from, and an
agent-run log is what an AI agent found when it ran the command line alone on a clip. Nothing here is current: the open
items these files list were carried into `ROADMAP.md` and `IDEAS.md` when each branch merged. **The live handoffs stay in
`docs/`:** `handoff-v04.md` (the 0.4 line, the usual one since 2026-10-27), `handoff-phone.md` (the phone-video scope),
`handoff-drift-band.md` (the drift stage's Test 4b, 2026-11-02) and `handoff-scene.md` once branch `scene` merges.

Paths in these files were written when they lived in `docs/`; `docs/handoff-x.md` in one of them now means
`docs/history/handoff-x.md`, and the `/scratch` paths they name are gone (the drive was replaced on 2026-10-28).
