# Field card { .field-card-title }

![The front of the mcDonald UAP Toolkit's field card. Film an object so it can be measured. Brace the phone. Pan only if you must. Keep a cloud, tree, roof, or the horizon in view. Set the zoom first, then leave it alone. Keep filming as long as you can see it. Keep the original file, uncut and unedited.](assets/field-card-front.png){ .field-card }

![The back of the field card. Then write it down. You: What is the time and location? Note your speed and direction if in a car, boat, or plane. Your view: What is the compass direction? Count fists up from the horizon. A fist held out covers about 10 degrees. The object: What is the distance to the object? Explain your measurement or estimate. mcDonald is a free, deterministic, frame-by-frame motion analyzer. mcdonald.bluemarblespace.org, with a QR code that leads there.](assets/field-card-back.png){ .field-card }
